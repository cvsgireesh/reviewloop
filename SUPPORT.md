# Getting help

Check [setup](README.md), [operations and troubleshooting](docs/OPERATIONS.md), and [recorded validation](docs/VALIDATION.md) first.

For a reproducible defect, open a [bug report](https://github.com/cvsgireesh/reviewloop/issues/new?template=bug_report.yml). For a proposed behavior change, open an [enhancement request](https://github.com/cvsgireesh/reviewloop/issues/new?template=enhancement.yml). Search existing issues before filing a duplicate.

Include your ReviewLoop commit/version, Node version, operating system, runtime type, and the smallest sanitized reproduction. State which checks you actually ran. Do not attach credentials, private source, full configuration/state directories, or unredacted logs. Replace repository, account and chat identifiers with placeholders.

Use [private security reporting](SECURITY.md) for vulnerabilities. This repository does not provide a hosted service or a guaranteed support response.
